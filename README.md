# Routiq

Routiq is isolated under `projects/routiq/` to protect the existing expense-tracker project under projects/smart-expense-tracker/. Within this project, `input/`, `output/` and `project-memory/` refer to the folders here. Agent, skill, phase and gate authorities remain in the workspace root; no authority files are duplicated.

IDs are scoped to Routiq and are not references to the root project's IDs. The source DOCX is a byte-identical copy of the supplied file. Generated reading notes are DERIVED.

See [the documentation guide](docs/README.md) for all project areas and shared workflow links, and [project configuration](project.config.md) for path routing. Read [current project state](project.state.md) for the current stage, recorded gate decisions and next action.
